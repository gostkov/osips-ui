# История изменений

## Не выпущено

### Исправлено

- При переключении сервера сбрасываются таблицы и диалоги; запоздалые ответы не подменяют данные нового сервера.
- JWT привязаны к постоянному идентификатору пользователя: старый токен не даёт доступ после удаления и повторного создания одноимённой учётной записи.
- Пароли длиннее 72 байт UTF-8 отклоняются с HTTP 422 вместо HTTP 500; добавлена проверка в интерфейсе.
- Права `lb:read` достаточно для открытия Load balancer; недоступные вкладки скрыты.
- Устранены циклические перенаправления для ограниченных ролей; при отсутствии доступных разделов открывается профиль.
- Статус загрузки адресных правил учитывает изменения `pattern` и `context_info`.
- Флаг `--no-service` не изменяет unit-файл и не вызывает `systemctl`.
- Swagger использует endpoint `/api/auth/token` для авторизации через OAuth2-форму.

### Обновлено

- Обновлены зависимости Python и frontend, а также lock-файлы.
- Gunicorn переведён на `uvicorn-worker`; отключён ненужный control socket.
- Добавлены регрессионные тесты backend, frontend и установщика; обновлена документация.

### При обновлении

- Миграция идентификаторов пользователей выполняется автоматически. Старые JWT перестают действовать — пользователям потребуется войти заново.
